**Task Type:** Image classification (binary classification)

**Input Format:**  
- Input images are JPEG files located in the folder `/sc-scratch/sc-scratch-ikim-guidlight/be-fair/mlzero/basic_prompt_data/MyImages/`, with filenames such as `image_16320.jpg`.
- For prediction, the input is a folder path containing new images.

**Prediction Output Format:**  
- For each input image, output a malignancy probability (a float between 0 and 1).

**Additional Details:**  
- The model should classify skin lesion images as malignant or benign.
- The evaluation metric is Area Under the Receiver Operator Curve (AUROC).
