Certainly! Here is a **minimal, robust bash script** that:

- Creates a conda env in a specific folder with Python 3.11
- Activates it
- Installs `uv` via pip
- Installs requirements from two files using `uv pip install` (with `--prerelease=allow`)
- Does **not** upgrade/reinstall `autogluon.multimodal` if already correct
- Runs your Python script

**Assumptions:**
- `conda` is in your PATH
- You want a local env at `/home/anri21/be-fair/mlzero/28-basic_prompt/node_0/conda_env`
- You want to use `uv pip install ... --prerelease=allow -r ... -r ...`
- The requirements files specify exact versions (so `uv` will not upgrade/reinstall if already satisfied)

---

```bash
#!/bin/bash
set -e

ENV_DIR="/home/anri21/be-fair/mlzero/28-basic_prompt/node_0/conda_env"
PYTHON_VERSION="3.11"
REQ_COMMON="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/_common/requirements.txt"
REQ_MM="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/autogluon.multimodal/requirements.txt"
PY_SCRIPT="/home/anri21/be-fair/mlzero/28-basic_prompt/node_0/generated_code.py"

# 1. Create conda env if not exists
if [ ! -d "$ENV_DIR" ]; then
    conda create -y -p "$ENV_DIR" python=$PYTHON_VERSION
fi

# 2. Activate env
source "$(conda info --base)/etc/profile.d/conda.sh"
conda activate "$ENV_DIR"

# 3. Install uv
pip install --upgrade pip
pip install uv

# 4. Install requirements with uv (prerelease allowed, exact versions)
uv pip install --prerelease=allow -r "$REQ_MM" -r "$REQ_COMMON"

# 5. Run the Python script
python "$PY_SCRIPT"
```

---

**Notes:**
- This script is minimal and robust.
- `uv pip install` will only install what's missing or wrong version, and will not upgrade/reinstall if already correct.
- If `autogluon.multimodal` is already at the correct version, it will not be reinstalled.
- If you want to force a clean install every time, add `conda remove -y -p "$ENV_DIR" --all` before creation.
- If you want to ensure `uv` is always the latest, keep `pip install uv` as above.

**Save as** e.g. `run_mlzero.sh`, `chmod +x run_mlzero.sh`, and run.
