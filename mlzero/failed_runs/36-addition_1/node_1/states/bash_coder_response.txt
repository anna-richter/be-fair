Here is a **minimal, executable bash script** for your requirements:

```bash
#!/usr/bin/env bash
set -e

ENV_DIR="/home/anri21/be-fair/mlzero/36-addition_1/node_1/conda_env"
PYTHON_VERSION="3.11"
REQ_COMMON="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/_common/requirements.txt"
REQ_ML="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/machine learning/requirements.txt"
PY_SCRIPT="/home/anri21/be-fair/mlzero/36-addition_1/node_1/generated_code.py"

# 1. Create conda env if not exists
if [ ! -d "$ENV_DIR" ]; then
    conda create -y -p "$ENV_DIR" python="$PYTHON_VERSION"
fi

# 2. Activate env
source "$(conda info --base)/etc/profile.d/conda.sh"
conda activate "$ENV_DIR"

# 3. Install uv
pip install uv

# 4. Install requirements with uv (prerelease allowed, both files)
uv pip install -r "$REQ_ML" --prerelease=allow -r "$REQ_COMMON"

# 5. Install extra packages needed by the script
pip install pandas scikit-learn torch torchvision pillow

# 6. Run the Python script
python "$PY_SCRIPT"
```

**How to use:**
1. Save as `run_node1.sh`
2. `chmod +x run_node1.sh`
3. Run with `./run_node1.sh`

**Notes:**
- This script assumes you have `conda` available in your shell.
- It installs all extra packages needed for the script (`pandas scikit-learn torch torchvision pillow`).
- It does not recreate the environment if it already exists.
- If your requirements file or folder names contain spaces, as in `machine learning`, the path is quoted and should work as written.
- If you want to always recreate the environment, add `conda remove -y -p "$ENV_DIR" --all` before creation.
