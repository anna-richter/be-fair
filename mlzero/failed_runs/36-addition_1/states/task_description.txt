**Task Type:** Image classification (binary classification)

**Input Format:** Images of skin lesions.

**Prediction Output Format:** For each input image, output a malignancy probability (a float between 0 and 1).

**Additional Details:**  
- The model should classify each lesion as malignant or benign by predicting the probability of malignancy.
- The evaluation metric is Area under the receiver operator curve (AUROC).
- The model should be saved.
- A function is required that takes a folder path containing new images and returns a malignancy probability for each image.
