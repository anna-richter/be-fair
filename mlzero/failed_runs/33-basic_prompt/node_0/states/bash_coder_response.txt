Certainly! Here is a **minimal, robust bash script** that:

- Creates a conda env in a specific folder with Python 3.11
- Activates it
- Installs `uv` via pip
- Installs requirements from two files using `uv pip install` (with `--prerelease=allow`)
- Does **not** upgrade/reinstall `autogluon.multimodal` if already correct
- Runs your Python script

**Save this as `run_mlzero.sh` and make it executable (`chmod +x run_mlzero.sh`).**

```bash
#!/usr/bin/env bash
set -e

# Paths
ENV_DIR="/home/anri21/be-fair/mlzero/33-basic_prompt/node_0/conda_env"
PYTHON_VERSION="3.11"
REQ_COMMON="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/_common/requirements.txt"
REQ_MM="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/autogluon.multimodal/requirements.txt"
PY_SCRIPT="/home/anri21/be-fair/mlzero/33-basic_prompt/node_0/generated_code.py"

# 1. Create conda env if not exists
if [ ! -d "$ENV_DIR" ]; then
    conda create -y -p "$ENV_DIR" python=$PYTHON_VERSION
fi

# 2. Activate env
eval "$(conda shell.bash hook)"
conda activate "$ENV_DIR"

# 3. Install uv if not present
if ! python -m pip show uv &>/dev/null; then
    python -m pip install uv
fi

# 4. Install requirements with uv (prerelease allowed)
uv pip install --prerelease=allow -r "$REQ_MM" -r "$REQ_COMMON"

# 5. Run the Python script
python "$PY_SCRIPT"
```

---

**Notes:**
- This script is minimal and robust.
- `uv pip install` will only install what is needed, not upgrade existing packages unless required by the requirements.
- If `autogluon.multimodal` is already at the correct version, it will not be reinstalled.
- The script will error out if any step fails (`set -e`).
- If you want to ensure `conda` is available, run this script from a shell where `conda` is initialized (e.g., `conda init bash` has been run previously).

---

**If you need to run this in a non-interactive shell, you may want to add `source ~/.bashrc` before the `eval` line, depending on your system.**
