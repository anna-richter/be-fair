Certainly! Here is a **minimal, executable bash script** that does exactly what you described:

```bash
#!/bin/bash
set -e

ENV_DIR="/home/anri21/be-fair/mlzero/28-basic_prompt/node_0/conda_env"
PYTHON_VERSION="3.11"
REQ_COMMON="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/_common/requirements.txt"
REQ_MM="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/autogluon.multimodal/requirements.txt"
PY_SCRIPT="/home/anri21/be-fair/mlzero/28-basic_prompt/node_0/generated_code.py"

# 1. Create conda environment in the specified folder if not exists
if [ ! -d "$ENV_DIR" ]; then
    conda create -y -p "$ENV_DIR" python=$PYTHON_VERSION
fi

# 2. Activate the environment
# shellcheck disable=SC1091
source "$(conda info --base)/etc/profile.d/conda.sh"
conda activate "$ENV_DIR"

# 3. Install uv and required packages
pip install uv

uv pip install --strict --prerelease=allow \
    -r "$REQ_MM" \
    -r "$REQ_COMMON"

# 4. Run the Python script
python "$PY_SCRIPT"
```

---

**Notes:**
- The script creates the conda environment at the specified path if it doesn't exist.
- It activates the environment using `conda activate`.
- Installs `uv` via pip.
- Installs only the exact packages (and their dependencies) from the two requirements files using `uv pip install --strict --prerelease=allow ...`.
- Does **not** upgrade or reinstall `autogluon.multimodal` if already at the correct version (as `uv` will skip if satisfied).
- Runs your Python script at the end.
