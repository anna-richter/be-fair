Certainly! Here is a **minimal, executable bash script** that does exactly what you described:

```bash
#!/usr/bin/env bash
set -e

# Set variables
ENV_DIR="/home/anri21/be-fair/mlzero/29-basic_prompt/node_0/conda_env"
PYTHON_VERSION="3.11"
REQ_COMMON="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/_common/requirements.txt"
REQ_MM="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/autogluon.multimodal/requirements.txt"
PY_SCRIPT="/home/anri21/be-fair/mlzero/29-basic_prompt/node_0/generated_code.py"

# 1. Create conda environment in the specified folder
conda create -y -p "$ENV_DIR" python=$PYTHON_VERSION

# 2. Activate the environment
source "$(conda info --base)/etc/profile.d/conda.sh"
conda activate "$ENV_DIR"

# 3. Install uv via pip
pip install uv

# 4. Install requirements using uv, only exact packages and dependencies, allow prerelease
uv pip install --prerelease=allow -r "$REQ_MM" -r "$REQ_COMMON"

# 5. Run the Python script
python "$PY_SCRIPT"
```

---

**Notes:**
- This script assumes `conda` is available in your PATH.
- It uses `uv pip install` with `--prerelease=allow` and both requirements files, as requested.
- It does **not** upgrade or reinstall `autogluon.multimodal` if already at the correct version (uv/pip will skip if satisfied).
- It activates the environment in a POSIX-compliant way.
- It runs your Python script at the end.

**Usage:**
Save as `run_mlzero.sh`, `chmod +x run_mlzero.sh`, and execute.  
If you want to re-run, you may want to `conda remove -p "$ENV_DIR" --all -y` first to start fresh.
