**Task Type:** Image classification (binary classification)

**Input Format:**  
- Input images of skin lesions (image files; image file names are referenced in the dataset as `image_name`).
- For prediction, a folder path containing new images.

**Prediction Output Format:**  
- For each input image, output a malignancy probability (a float between 0 and 1).

**Additional Details:**  
- The model should classify each lesion as malignant or benign.
- The evaluation metric is Area Under the Receiver Operator Curve (AUROC).
- The trained model should be saved.
- A function must be provided that takes a folder path of new images and returns a malignancy probability for each image.
