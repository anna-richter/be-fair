Certainly! Here is a **minimal, executable bash script** that:

- Creates a conda environment in the specified folder with Python 3.11
- Activates the environment
- Installs `uv` via pip
- Installs the exact required packages from the two requirements files using `uv pip install ... --prerelease=allow ...`
- Does **not** upgrade/reinstall `autogluon.multimodal` if already at the correct version
- Runs the Python script

**Assumptions:**
- `conda` is available in your PATH
- The requirements files exist and are readable
- The script is run with permissions to create folders and files in the specified locations

```bash
#!/bin/bash
set -e

ENV_DIR="/home/anri21/be-fair/mlzero/37-addition_1/node_0/conda_env"
PYTHON_VERSION="3.11"
REQ_COMMON="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/_common/requirements.txt"
REQ_MM="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/autogluon.multimodal/requirements.txt"
PY_SCRIPT="/home/anri21/be-fair/mlzero/37-addition_1/node_0/generated_code.py"

# 1. Create conda env if not exists
if [ ! -d "$ENV_DIR" ]; then
    conda create -y -p "$ENV_DIR" python="$PYTHON_VERSION"
fi

# 2. Activate conda env
# shellcheck disable=SC1091
source "$(conda info --base)/etc/profile.d/conda.sh"
conda activate "$ENV_DIR"

# 3. Install uv
pip install --no-cache-dir uv

# 4. Install requirements with uv, only as specified, allow prerelease
uv pip install --prerelease=allow -r "$REQ_MM" -r "$REQ_COMMON"

# 5. Run the Python script
python "$PY_SCRIPT"
```

---

**Notes:**
- This script does not forcibly upgrade/reinstall `autogluon.multimodal` if already present and at the correct version (as per your requirements).
- `uv pip install` will only install what is specified in the requirements files, with dependencies, and will not upgrade packages not listed.
- The script is minimal and does not include extra checks or verbose output.
- If you want to ensure the environment is always fresh, you can add `conda remove -y -p "$ENV_DIR" --all` before creation, but that's not included here for safety.

**Usage:**  
Save as `run_mlzero.sh`, `chmod +x run_mlzero.sh`, then run.
