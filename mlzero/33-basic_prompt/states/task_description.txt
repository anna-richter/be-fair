**Task Type:** Image classification (binary classification)

**Input Format:** Images of skin lesions (image files referenced by image_name in the dataset).

**Prediction Output Format:** For each input image, output a malignancy probability (a float between 0 and 1).

**Additional Details:**  
- The model should classify lesions as malignant or benign.
- Evaluation metric: Area under the receiver operator curve (AUROC).
- A function is required that takes a folder path of new images and returns a malignancy probability for each image.
