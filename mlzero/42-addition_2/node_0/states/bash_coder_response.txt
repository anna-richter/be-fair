Certainly! Here is a **minimal, robust bash script** that:

- Creates a conda environment in the specified folder with Python 3.11
- Activates the environment
- Installs `uv` via pip
- Installs **only** the packages (and their dependencies) from the two requirements files using `uv pip install ...`
- Does **not** upgrade/reinstall `autogluon.multimodal` if already at the correct version
- Runs the Python script

**Assumptions:**
- `conda` is available in your shell
- `uv` is available via pip (which it is)
- You want a minimal script (no error checking, no extra output)
- The requirements files exist and are readable

```bash
#!/bin/bash
set -e

ENV_DIR="/sc-scratch/sc-scratch-ikim-guidlight/be-fair/mlzero/42-addition_2/node_0/conda_env"
REQ_COMMON="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/_common/requirements.txt"
REQ_MM="/home/anri21/.conda/envs/mlzero_env/lib/python3.12/site-packages/autogluon/assistant/tools_registry/autogluon.multimodal/requirements.txt"
PY_SCRIPT="/sc-scratch/sc-scratch-ikim-guidlight/be-fair/mlzero/42-addition_2/node_0/generated_code.py"

# 1. Create conda env if not exists
if [ ! -d "$ENV_DIR" ]; then
    conda create -y -p "$ENV_DIR" python=3.11
fi

# 2. Activate env
source "$(conda info --base)/etc/profile.d/conda.sh"
conda activate "$ENV_DIR"

# 3. Install uv
pip install uv

# 4. Install requirements with uv (prerelease allowed, no upgrades)
uv pip install --prerelease=allow -r "$REQ_MM" -r "$REQ_COMMON"

# 5. Run the Python script
python "$PY_SCRIPT"
```

---

**How this works:**

- The environment is created at the specified path if it doesn't exist.
- The script uses `conda activate` (requires `conda` shell integration).
- `uv pip install` is used with both requirements files and `--prerelease=allow` as requested.
- No explicit upgrade or reinstall of `autogluon.multimodal` is performed; `uv` will only install what's missing or required by the requirements files.
- The Python script is executed at the end.

---

**Usage:**
Save as `run.sh`, `chmod +x run.sh`, then run with `./run.sh`.

---

**If you want to ensure the environment is always fresh, add `conda remove -y -p "$ENV_DIR" --all` before creation.**
